# apps/references — статические данные (заглушка)

По решению по проекту основной источник данных конструктора живёт рядом с кодом:

- `apps/extension/src/references/cakeData.json` — вес, основы, начинки, кремы, декор, правила цен;
- `apps/extension/src/references/siteContent.json` — тексты лендинга, галерея, контакты, доставка, юридические тексты.

Эта папка зарезервирована под будущие статические артефакты, которые нужны
не только приложению:

| Что сюда переедет | Зачем |
|---|---|
| `catalog.export.json` | Выгрузка ассортимента для CRM/1С кондитерской |
| `telegram-templates/*.txt` | Шаблоны сообщений для бота и рассылок |
| `price-list.csv` | Прайс для менеджеров и партнёров |
| `docs/*.pdf` | Договоры, политика ПД, презентация платформы |

## Формат обмена с API

`apps/api` получает заказ в формате `Order` (см. `apps/extension/src/types/index.ts`).
Если понадобится серверная валидация каталога (например, проверка, что цена
в заказе совпадает с прайсом), скопируйте `cakeData.json` сюда и импортируйте
его из API — так данные останутся версионируемыми и доступными без сборки фронтенда.

Пока папка пуста намеренно: не дублируем JSON, чтобы не расходились цены.
