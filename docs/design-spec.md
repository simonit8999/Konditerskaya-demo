# Дизайн-спецификация «Кондитерский Рай» (B2B)

Документ фиксирует визуальный язык, анимации и правила контента. Реализация —
в коде: токены в `apps/extension/tailwind.config.js`, иконки —
`src/components/ui/Icon.tsx`, тексты — `src/references/siteContent.json`.

## 1. Позиционирование

Продукт для **кондитерских** (B2B): платформа, которая принимает онлайн-заказы
за кондитера. Оффер: «Ваши торты — в один клик от клиента!». Тон: деловой,
уверенный, но с кондитерской теплотой (эмодзи только в Telegram-сообщениях,
не в интерфейсе).

Ключевые сообщения:
1. Клиент собирает торт сам — кондитер не тратит время на переписку.
2. Цена видна сразу — меньше споров и отмен.
3. Заказ приходит в Telegram с составом и контактами.
4. Запуск за один день, бренд кондитерской сохраняется.

| `gold` | `#DAA520` | основной CTA, иконки, линии | **не как цвет текста на светлом** (2.1:1) |
| `caramel` | `#C68E17` | hover, крупные акценты, итог | — |
| `berry` | `#DC143C` | бейдж корзины, опасные действия, ошибки, ягоды в превью | — |
| `ink` | `#333333` | основной текст | — |
| `cocoa` | `#5A3A3A` | заголовки, текст на золоте | — |
| `line` | `#EADCC3` | бордеры, разделители | — |

Контраст (проверено):
- `ink` на `cream` ≈ 12.6:1, `cocoa` на `cream` ≈ 9.9:1.
- Текст кнопки CTA — `cocoa` на градиенте `gold → caramel` ≈ 6:1.
- Белый текст на `berry` ≈ 4.9:1 — годится для вторичных кнопок.

Фактуры: слабая «бумажная» зернистость (`.grain`, opacity 3 %), размытые
пятна `blush`/`mint` (`blur-3xl`, 40 %), «глазурная» волна между секциями.

## 4. Иконки

Контурные, 24×24, `stroke-width 1.5`, `currentColor`, скругления `round`.
Компонент `<Icon name="…" />`.

Набор: `cake`, `cupcake`, `cream`, `berries`, `calculator`, `telegram`, `whatsapp`,
`clock`, `calendar`, `palette`, `cart`, `heart`, `check`, `arrowRight`,
`chevronDown`, `trash`, `plus`, `minus`, `truck`, `mapPin`, `phone`, `mail`,
`sparkle`, `gift`, `leaf`, `close`, `menu`, `copy`, `download`, `star`, `info`, `edit`,
`bell`, `chart`, `wallet`, `user`, `ban`, `chat`.

Правила: брендовые Telegram/WhatsApp — по официальным брендбукам при крупных
размерах; контурные версии — только для мелких подписей. Иконка не дублирует
текст кнопки, а дополняет его.

## 5. Анимации

Базовые кривые: `silk = cubic-bezier(0.22, 1, 0.36, 1)`, пружина
`{ stiffness: 320, damping: 26 }`. Длительности: 160 / 260 / 420 мс.

| Где | Триггер | Эффект |
|---|---|---|
| Переход страниц | смена роута | fade + `y 12→0`, выход `y -8`, 280 мс, `AnimatePresence mode="wait"` |
| Hero | загрузка | badge → H1 → подзаголовок → CTA → статистика, задержка 60–120 мс, фото `y 28→0` |
| Секции | `whileInView` | `opacity 0→1`, `y 24→0`, 450 мс, `once`, `margin -80px` |
| Карточки преимуществ | stagger | 70 мс на карточку + hover `-translate-y-1` |
| Галерея | hover | фото `scale 1.04` за 700 мс, подпись появляется |
| Шаги конструктора | выбор опции | рамка `caramel`, «галочка» пружиной, слои декора fade/slide |
| Цена | изменение | цифры прокручиваются (`AnimatePresence` + `y ±14`), 220 мс |
| Корзина | добавление | тост снизу + бейдж счётчика |
| Модалка заказа | open/close | backdrop fade, панель `scale .98→1`, 240 мс, Escape |
| PWA-события | оффлайн / установка / обновление | выезжающие плашки, `role="status"` |

`prefers-reduced-motion`: все эффекты сводятся к fade (хук `useReducedMotion`
и медиазапрос в `styles/index.css`).

## 6. Сетки и компоненты

- Контейнер: `max-w-6xl`, отступы 16/24/32 px.
- Радиусы: карточки 24 px (`rounded-3xl`), крупные блоки 32 px (`rounded-4xl`), кнопки — pill.
- Тени: `shadow-card` (лёгкая), `shadow-soft` (hover/модалки), `shadow-gold` (CTA).
- Кнопки: `primary` (золотой градиент, текст `cocoa-dark`), `secondary` (berry, белый),
  `outline` (рамка карамели), `ghost`, `danger`. Высоты 36/44/52 px.
- Поля: высота 48 px, фон `cream-50`, рамка `line`, фокус — золотое кольцо.
- Обязательные состояния: hover, focus-visible, active, disabled, loading,
  ошибка (текст под полем), пустое состояние.

## 7.1. Статусы и уведомления

| Статус | Подпись | Кто ставит | Текст клиенту |
|---|---|---|---|
| `new` | Новый | система | «Заказ принят и ждёт подтверждения кондитера» |
| `confirmed` | Подтверждён · готовится | владелец | «Кондитер подтвердил заказ и уже готовит его» |
| `ready` | Готов к выдаче | владелец | «Торт готов — можно забирать или ждать доставку» |
| `completed` | Забран / доставлен | владелец | «Спасибо за заказ!» |
| `declined` | Не подтверждён | владелец | «Не удалось подтвердить заказ — свяжитесь с нами» |

Цвета чипов: `new` — золото, `confirmed` — карамель, `ready` — мята,
`completed` — нейтральный, `declined` — berry.

Уведомления: колокольчик в шапке с бейджем, панель с отметкой о прочтении,
баннер на `/orders` и `/order/:id`. Внутри панели — честная подпись, что
Telegram/email/push появятся позже. Демо-кабинет помечается бейджем
«Демо-режим», демо-заказы — бейджем «Демо».

## 8. Манифест PWA

`name` — «Кондитерский Рай — конструктор тортов для кондитерских»,
`short_name` — «Кондитерский Рай», `lang: ru`, `start_url`/`scope: "./"`,
`display: standalone`, `theme_color`/`background_color: #FFF8E1`,
иконки 192/512 + maskable (знак в безопасной зоне 62 %), shortcuts на
конструктор, заказы и доставку. Полный файл — `apps/extension/public/manifest.json`.

## 9. Контент: правила

- Заголовки — про выгоду кондитера, не про «вкусненько».
- В каждом блоке один призыв к действию.
- Демо-данные помечаются: плашка «демо-режим» в hero, сноска в подвале,
  «(демо-адрес)» в контактах.
- Числа — с неразрывным пробелом: `6 620 ₽`.
- Телефон — маска `+7 (999) 123-45-67`, одинаково в интерфейсе и в Telegram.
- Ошибки — что сделать, а не «неверный ввод»: «Введите телефон полностью».
